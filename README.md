# Ajay Kumar Yadav — Cinematic Portfolio

Preview-first portfolio built with Next.js, TypeScript and GSAP ScrollTrigger.

## Branch strategy
- `main`: initial README only; website work is isolated on `portfolio-preview`.
- `portfolio-preview`: active website implementation.
- Do not promote to production until Ajay approves the preview.

## Six-scene structure
Intro · About · Architecture & engineering · Selected work · Skills & AI · Contact.

## Personal photo assets
Add approved original photographs under `public/images` and wire them into the hero and About scenes. Do not substitute generated face imagery for the original photographs. The current page intentionally uses placeholders until image binaries are added.

## Local setup
```bash
npm install
npm run dev
```

## Before launch
Verify contact details, project descriptions, achievement metrics and resume; add approved photos and resume; test accessibility, mobile layout and reduced-motion behavior; verify Vercel Preview before production promotion.
